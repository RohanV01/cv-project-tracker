01Phase 1

From Working Demo to Production Tool

The tracker isn't a mockup, it's already running. This phase turns it into a hardened, production tool CiVentiChem's own team operates day to day.

Problem

Project status today lives in scattered Excel sheets and people's heads. Documenting day-to-day progress is manual and inconsistent, and leadership doesn't have real-time visibility into what's on track versus at risk, making RCAs and strategy calls harder than they should be.

Solution

Deploy a live, structured tracker where teams document work as they go, and leadership sees real-time status across every project on one dashboard.

Value unlock

Easier day-to-day documentation for teams, and real visibility for leadership, so root-cause analysis and strategic decisions are based on live data, not guesswork.

1
Expand the demo into a full-fledged tool
Take the working prototype already built and demonstrated, and harden it: multi-user ready, backed up, and owned end-to-end by CiVentiChem's own infrastructure, not a laptop.
2
Understand the infrastructure in depth
Beyond the basic specs already shared, go hands-on: network topology, concurrency limits, backup/RAID status, and IT policy, before anything gets deployed.
3
Deploy, then train the team
Install the tool as a resilient local service on CiVentiChem's server, then run hands-on training so their own people can operate it unassisted.

02Phase 2

GPU Infrastructure & Inquiry Automation

Before any AI can run locally, CiVentiChem needs the right hardware in place. This phase starts there, then builds the first automation on top of it.

Problem

Incoming customer inquiries are handled manually today. Drafting proposals takes real time and pulls senior people away from higher-value work, slowing down how quickly CiVentiChem can respond to new business.

Solution

Automate the inquiry-to-proposal process so incoming requests become structured, ready-to-send proposals quickly, while standing up the GPU infrastructure the AI layer needs next.

Value unlock

Faster response times to prospective clients, less manual drafting work for senior staff, more consistent proposals, and a real edge in how fast CiVentiChem can move on new business.

1
Understand the scale and scope of the data
Sit with CiVentiChem's team to review the size and shape of the historical archive, this directly drives the GPU sizing decision.
2
Jointly decide the GPU specification
Based on that conversation, agree on the exact GPU required, minimum 24 GB VRAM, sized to the confirmed archive scale rather than over-buying data-center-grade hardware.
3
CiVentiChem acquires and deploys the GPU server
The gating step: this server unlocks both the rest of Phase 2 and all of Phase 3. Recommended vendor: Zotac.
4
Document the go/no-go SOP
CiVentiChem defines the SOP for how a decision is made on whether to pursue an incoming project, the criteria, the people involved, the logic. This SOP is the basis the automation is built on.
5
Build and deploy Incoming Inquiry Automation
Once the server is live and the SOP is documented, build the automation that turns incoming customer inquiries into structured proposals, applying that same go/no-go logic.

03Phase 3

Build & Deploy the AI Chatbot on Historical Data

Running on the GPU server deployed in Phase 2, turn CiVentiChem's structured history into a chatbot the team can ask questions of, entirely offline.

Problem

30-40 years of hard-won chemistry knowledge lives in the heads of senior chemists and old paper notebooks. When experienced people retire or leave, that knowledge walks out with them, and teams end up re-solving problems CiVentiChem already solved years ago.

Solution

Turn that 30-40 year archive into a chatbot any team member can ask "how did we solve this before," grounded in CiVentiChem's own real history, running entirely offline.

Value unlock

Institutional knowledge survives staff turnover, R&D solves problems faster by learning from past work instead of repeating it, and CiVentiChem builds a competitive edge no competitor can copy.

1
Develop and deploy the chatbot
Built on the historical archive, so answers are grounded in CiVentiChem's own project history, not generic knowledge.
